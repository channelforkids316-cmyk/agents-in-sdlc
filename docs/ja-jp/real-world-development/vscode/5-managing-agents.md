Copilot をエージェントモードで使うと、コードベースを調べ、変更を提案し、ファイルを編集して、コマンドを実行します。この作業は自分のマシンでリアルタイムに実行されます。VS Code の Copilot Chat では、ツールの呼び出しやファイルの編集を随時確認できます。差分をインラインでレビューし、個々の変更を受け入れるか取り消し、会話に追加のプロンプトを送って作業を調整できます。エディターを離れる必要はありません。

この演習では、次の内容を学習します。

- アクセシビリティエージェントの作業をリアルタイムで監視します。
- 提案されたファイル編集をレビューして受け入れます。
- セッションの途中でエージェントに指示を送り、ハイコントラストに加えてライトモードを追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ用カスタムエージェントが、ハイコントラストモードを実装しています。作業中、デザインチームから新たな依頼がありました。既定のテーマが暗すぎると感じるユーザー向けに、ライトモードも切り替えられるようにします。新しい会話を始めるのではなく、既存のセッションに追加の指示を送ります。

## Copilot の進行状況を監視する

Copilot Chat ビューには、エージェントが進めた手順が表示されます。調査したファイル、実行したコマンド、提案された編集を確認できます。各ファイル編集は差分と **Keep** / **Undo** の操作とともにチャットに表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、ツールの呼び出しを確認します。ファイルの読み取りや編集、実行を求められたターミナルコマンドが表示されます。
3. エージェントがファイルを編集すると、差分がインラインで表示されます。
    - 変更を受け入れるには **Keep** を選択します。
    - 変更を元に戻してエージェントに再度作業させるには **Undo** を選択します。
4. チャット上部の **Files changed** を開き、このセッションで変更されたファイル全体を確認することもできます。

> [!NOTE]
> ターミナルコマンドの実行などに許可が必要な場合、エージェントは一時停止して **Allow** を表示します。内容を確認して、許可してもよいコマンドだけを承認してください。

5. エージェントがハイコントラストモードの実装を終えるまで待ちます。最後に、変更内容をまとめたメッセージが表示されます。

## ライトモードを追加するようエージェントに指示する

ハイコントラストモードができたら、同じ会話でライトモードの切り替え機能も追加します。同じチャットセッションを続けるため、エージェントは前の作業で変更したコンポーネント、スタイルの方針、local storage の使い方などのコンテキストを保持しています。

1. Copilot Chat の入力欄に、次の追加プロンプトを送信します。

    ```plaintext
    Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
    ```

2. エージェントは既存の変更を確認し、ライトモードの追加を提案します。
3. 変更が提示されるたびに **Keep** または **Undo** を選びます。
4. エージェントが望まない方向に進んだ場合 (たとえば、好みと違う方法で切り替え UI をリファクタリングする場合) は、チャット入力欄の横にある **Stop** ボタンで停止し、追加の説明を送ります。

> [!TIP]
> 進行中のセッションに指示を送ると、最初からやり直すより短時間で調整できます。「CSS を簡潔にして、セレクターの重複ではなく CSS 変数を使う」「3 つ目の切り替えを追加せず、既存の設定パネルにライトモードを組み込む」「両方の切り替えにキーボードショートカットを追加する」など、追加のプロンプトで方向を調整したり範囲を広げたりできます。

## 作業内容をレビューする

作業をコミットする前に、エージェントが変更した内容を確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストが更新されているはずです。
3. 変更されたファイルをいくつか開き、差分を確認します。カスタムエージェントのアクセシビリティの方針 (ARIA 属性、キーボード操作、セマンティック HTML、local storage への保存) が反映されていることを確認します。
4. 内容に問題がなければ **Source Control** パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェントモードを使って、進行中のセッションを監視し、方向付けました。ファイル編集を確認し、変更を受け入れるか取り消し、コンテキストを保持したまま追加プロンプトで作業を拡張しました。

このレッスンでは、次の内容を学習しました。

- エージェントの作業をリアルタイムで監視する方法。
- 個々のファイル編集を受け入れる方法と取り消す方法。
- 追加プロンプトを使って進行中のセッションを調整する方法。
